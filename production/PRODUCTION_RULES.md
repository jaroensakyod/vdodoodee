# Production Rules — AI video storyboard

## เป้าหมายตอน

- เป้าหมาย 5 นาที = 300 วินาที; 38 generations เป็นค่าอ้างอิง (เฉลี่ยประมาณ 7.9 วินาทีต่อคลิป)
- แต่ละคลิปยาว 6–10 วินาที; ต้องนับ duration รวมจากคลิปจริงทุกครั้ง อย่าระบุว่าได้ 5:00 หากยังไม่บวกเวลา
- สคริปต์/บทพูดภาษาไทยให้อ่านออกเสียงได้ในเวลาที่กำหนด มีช่องว่างให้การแสดง หายใจ และ reaction

## Hook และจังหวะ

- ภายใน 0–2 วินาทีมีสิ่งชวนสงสัย: วัตถุผิดปกติ ปฏิกิริยาที่อ่านไม่ออก คำพูดชวนสะดุด ภัยที่กำลังเข้าใกล้ หรือการกระทำที่ขัดกับสิ่งคาด
- ก่อนจบคลิปให้มี mini-turn: สายตาเปลี่ยน ข้อมูลใหม่ คำถามที่ยังไม่ตอบ การตัดสินใจ หรือภาพต่อเนื่องที่ชวนดูช็อตหน้า
- ไม่จำเป็นต้องใส่ plot twist ทุกคลิป; ให้จังหวะสงสัยและ payoff สลับกับช่วงพักอารมณ์
- ทุกประมาณ 20–30 วินาทีควรมีคำถาม/ความเปลี่ยนแปลงใหม่ แต่รักษาความต่อเนื่องทางอารมณ์

## บทพูด

- ประโยคหนึ่งต้องจบในคลิปที่เริ่มพูด หากยาวเกินแบ่งเป็นหน่วยความหมายที่จบได้ในคลิปก่อนหน้า ห้ามตัดกลางคำ/กลางประโยคโดยไม่ตั้งใจ
- แยก speaker, dialogue, delivery, pause และ reaction; dialogue ต้องเป็นข้อความพูดจริง ไม่ใช่คำสั่งภาพ
- ให้บทมีเนื้อพอให้ตัวละครโต้ตอบอย่างเป็นธรรมชาติ แต่อย่าฝืนอัดคำพูดจนเกินเวลาหรือกลบการแสดง
- คำเรียก/ราชาศัพท์ใช้สม่ำเสมอตามสถานะ; หากมีการแก้ให้ปรับทั้งตอน

## Continuity: End Frame → First Frame

คลิปที่เป็นการกระทำต่อเนื่องในฉากเดียวกันต้องบันทึก:

- `Start frame`: ภาพนิ่ง ณ เฟรมแรก รวมตำแหน่งตัวละคร มือ/พร็อพ ทิศสายตา แสง และองค์ประกอบ
- `End frame`: ภาพนิ่งสุดท้ายที่คลิปถัดไปจะเริ่มจาก
- `Bridge`: อ้าง `previous clip END → this clip FIRST` และระบุว่ามีอะไรเปลี่ยนระหว่างทาง
- รักษาหน้า/รูปร่าง/ทรงผม/ชุด/คราบ/อาวุธ/บาดแผล/ตำแหน่ง/แสง/ฉาก/ทิศทางการเคลื่อนที่
- สำหรับช็อตต่อเนื่อง ห้ามสร้าง first frame ใหม่แบบอิสระ; ใช้ end frame จากคลิปก่อนเป็น reference
- หากข้ามเวลา/สถานที่ ให้ติดป้าย `CUT` และกำหนดภาพแรกใหม่พร้อมเหตุผล

## Shot ID และสถานะ

รูปแบบ ID: `EP01-S08-C036` = ตอน 01, sequence 08, clip 036. เลขเป็นสองหลักขั้นต่ำ; เมื่อเกิน 99 ใช้ 3 หลักทั้งหมดในตอนนั้นเพื่อไม่ให้สับสน

ทุก shot ต้องมี:

`ID | เวลา | duration | sequence | location/time | cast | costume IDs | first frame | action | dialogue/audio | camera | end frame | continuity bridge | hook/mini-turn | status`

สถานะ: `OUTLINE`, `DRAFT`, `LOCKED`, `GENERATED`, `APPROVED`, `NEEDS_REVISION`. การเขียนบทไม่เท่ากับการสร้าง/อนุมัติคลิป

## ภาพและการกำกับ

- ใช้ภาพ character reference ที่ผู้ใช้ล็อกเป็น anchor; ห้ามสลับใบหน้า รูปร่าง หรือชุดโดยไม่มีเหตุผล
- ระบุขนาดภาพและการเคลื่อนกล้องเท่าที่จำเป็น; รักษา screen direction ภายใน sequence
- ราชสำนักไทยแฟนตาซีเป็นโลกแต่ง อย่าอ้างว่าเป็นประวัติศาสตร์ยุคใดยุคหนึ่งถ้าไม่ล็อก
- Action อ่านง่ายและทำได้ใน 6–10 วินาที; หลีกเลี่ยง choreography หลายจังหวะใน shot เดียว
- Reaction shot มีเป้าหมายชัด: ผู้ชมต้องเห็นว่าใครรู้/ปิดบัง/เข้าใจผิดอะไร

## QA ก่อนล็อกตอน

- รวม duration จริงใกล้ 300 วินาที
- ทุก clip 6–10 วินาที
- hook ภายใน 2 วินาทีแรกและมีแรงส่งก่อนจบ
- ทุก dialogue จบใน clip และอ่านออกเสียงทันเวลา
- ตรวจ ID ไม่ซ้ำ, scene order, costume, prop, knowledge state, injury และ day/night
- ปลายตอนอัปเดต continuity log และ episode map
